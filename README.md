# dicegame - 互動式擲骰子(十八仔)賭博遊戲 1133334楊恩奇

這是一個基於 C# Windows Forms (WinForms) 開發的單人擲骰子賭博遊戲。玩家可以自由調整下注金額，與電腦（烘焙雞/莊家）進行經典的「十八仔」點數對決。專案內含非同步的骰子滾動動畫、動態縮放抖動特效，並整合了多種情境音效，提升遊戲的娛樂感與沉浸感。

## 🚀 遊戲特色與亮點

- **非同步動畫技術**：使用 `async/await` 與 `Task.Delay` 實現流暢且不卡頓的骰子滾動效果。
- **動態視覺特效**：在骰子滾動過程中，動態計算隨機的偏移量（X/Y 軸抖動）與縮放比例（Size 變化），並在停止時觸發「瞬間放大回彈」的視覺回饋。
- **完整的台式骰子規則**：自動過濾無效點數（強迫重擲直到出現對子），並精準計算「豹子（四顆相同）」、「三同單張」、「兩組對子」與「常規對子」之點數。
- **音效情境切換**：整合 `SoundPlayer` 播放經典音效，包含滾動聲、警告聲、玩家獲勝、電腦獲勝及平手音效。

## 🎲 點數計算規則 (十八仔)

每輪擲出 4 顆骰子，系統會自動重擲直到滿足以下有分條件：
1. **豹子（通殺/大獎）**：四顆骰子點數完全相同。屬於最高牌型（程式內設定為 100 分）。
2. **三顆相同 + 單張**：以那顆「單張」的點數作為最終分數（例如：5、5、5、3，分數為 3 分）。
3. **兩組對子**：取兩組對子中「點數較大」者作為最終分數（例如：6、6、3、3，分數為 6 分）。
4. **一組對子（常規）**：除去對子後，將另外兩顆「單張」的點數相加（例如：4、4、5、6，分數為 5+6 = 11 分）。

## 📖 操作說明
- 基本籌碼：遊戲開始時玩家擁有初始資金 $1,000 元。

- 進行下注：於微調按鈕 (numBet) 輸入欲下注的金額。

- 開始激戰：點擊開滾按鈕 (btnRoll)，按鈕會自動暫時停用以防重複觸發。

- 結果揭曉：等待雙方動畫結束後，底部標籤 (lblResult) 將顯示輸贏結果，並播放對應勝負音效與更新資金餘額。
